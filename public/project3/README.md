# Project 3 - Screensaver

This project displays images in an animated screensaver style.

## Setup Instructions

1. Place your images in the `project3/images/` folder
2. Name them sequentially: `image1.png`, `image2.png`, `image3.png`, etc.
3. Update the `imagePaths` array in `sketch.js` if you have a different number of images or different filenames

## Features

- Images float around the screen
- Smooth fade in/out effects
- Rotation animation
- Bouncing off edges
- Responsive to screen size
- Fullscreen support
